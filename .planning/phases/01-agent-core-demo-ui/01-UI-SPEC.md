## Spacing Scale

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge internal padding |
| sm | 8px | Message bubble padding, compact element spacing |
| md | 16px | Input field padding, card padding |

## Color

Theme: dark (suits demo/proof-of-concept context; reduces eye strain during live demos under bright lights).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f1117` | Page background, panel backgrounds |
| Secondary (30%) | `#1a1d27` | Message bubble (agent), input area background, panel header strip |
| Accent (10%) | `#6366f1` | Indigo-500 |
| Destructive | `#ef4444` | Escalation alert flash background only |

Accent (`#6366f1`) reserved for:
- Send button (default state)
- Industry selector active/selected border
- Lead status badge "hot" state background
- Stage progress indicator fill

Destructive (`#ef4444`) reserved for:
- Escalation alert flash panel (owner panel only, fires on `escalated: true` WebSocket event)

Additional semantic colors:
- Lead message bubble: `#2d2f3e` (slightly lighter than secondary — differentiates lead from agent)
- Agent message bubble: `#1a1d27` (secondary — matches panel background, subtly recessed)
- Text primary: `#f1f5f9` (slate-100)
- Text muted: `#64748b` (slate-500) — timestamps, labels
- Stage badge colors:
  - new: `#334155` bg / `#94a3b8` text (slate)
  - qualifying: `#1e3a5f` bg / `#60a5fa` text (blue)
  - hot: `#422006` bg / `#fb923c` text (orange)
  - booked: `#14532d` bg / `#4ade80` text (green)

## Layout Contract

### Startup Screen (IndustrySelector)

- Full viewport, centered vertically and horizontally
- Heading: "Piliin ang Industry" (24px semibold) — Filipino copy, matches agent language
- Three cards in a row (flex, gap: 32px): Dental · Aesthetics · Real Estate
- Each card: 200px × 160px, 16px padding, 8px border-radius, `#1a1d27` background, `#334155` border
- Hover state: border color → `#6366f1` (accent), transition 150ms ease
- Selected/active state: border 2px solid `#6366f1`, box-shadow: `0 0 0 2px rgba(99,102,241,0.25)`
- Persona name displayed below industry label: "Ate Ana", "Ate Bea", "Kuya Marco" (12px semibold, muted)
- "Simulan" (Start) button below cards: 44px height, accent background, full-width max 320px, 8px border-radius

### Split-Screen (post-selection)

- Layout: `display: flex; flex-direction: row; height: 100vh;`
- Left column (LeadChat): 50% width
- Right column (OwnerPanel): 50% width
- Divider: 1px solid `#334155` between columns
- Both columns: `display: flex; flex-direction: column;`

### LeadChat (left panel)

- Header strip (48px): "Lead Chat" label (18px semibold, left-aligned) + persona name (12px muted, right-aligned)
- Message list: flex-grow 1, overflow-y auto, 16px padding, 12px gap between bubbles
  - Lead messages: right-aligned, `#2d2f3e` background, 8px padding, 8px border-radius (top-left square on consecutive)
  - Agent messages: left-aligned, `#1a1d27` background, 8px padding, 8px border-radius
  - Streaming token state: agent bubble shows blinking cursor (CSS `::after` pseudo-element, 400ms blink) while tokens arrive
- Input area (72px fixed): `#1a1d27` background, 16px padding, flex row
  - Text input: flex-grow 1, 14px, 44px height, `#0f1117` background, `#334155` border, 8px border-radius
  - Send button: 44px × 44px, accent background (`#6366f1`), right arrow icon (lucide `Send`), 8px border-radius, disabled state: 40% opacity

### OwnerPanel (right panel)

- Header strip (48px): "Owner View" label (18px semibold) + stage badge (right-aligned)
- Stage badge: 12px semibold, 4px vertical / 8px horizontal padding, 4px border-radius, color per stage table above
- Conversation mirror: same visual treatment as LeadChat message list, but read-only (no input area)
- Escalation alert: position absolute, full-width, 64px height, `#ef4444` background, centered text: "HOT LEAD — Tawagan na!" (14px semibold, white) — displays on `escalated: true`, slides down from top with 200ms ease-in transition, auto-dismiss after 8 seconds

## Accessibility Baseline

- Touch targets: minimum 44×44px (Send button, industry cards, "Simulan" button) — WCAG 2.5.5
- Color contrast: text on backgrounds must meet WCAG AA (4.5:1 for body, 3:1 for large text)
  - `#f1f5f9` on `#0f1117`: ~14:1 — passes AAA
  - `#f1f5f9` on `#1a1d27`: ~12:1 — passes AAA
  - `#94a3b8` on `#0f1117`: ~5.5:1 — passes AA (muted text)
- Focus indicators: all interactive elements must have visible focus ring — `outline: 2px solid #6366f1; outline-offset: 2px;`
- Semantic HTML: `<main>`, `<section>`, `<button>` (not `<div>` for interactive elements), `aria-label` on icon-only Send button
- Screen reader: escalation alert uses `role="alert"` so it is announced automatically on appearance
