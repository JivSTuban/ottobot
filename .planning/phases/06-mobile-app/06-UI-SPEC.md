## Spacing Scale

Declared values (multiples of 4, as React Native numeric units = pt):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4 | Icon gaps, inline badge padding |
| sm | 8 | Row inner padding, list item gaps |
| md | 16 | Card padding, screen horizontal margin |
| lg | 24 | Section header spacing |
| xl | 32 | Top-of-screen safe area padding |
| 2xl | 48 | Bottom tab bar height |
| 3xl | 64 | Hero spacing (login screen logo area) |

**Exceptions:**
- Touchable targets: minimum 44pt height (WCAG 2.5.5, also Apple HIG minimum). Applied to all `TouchableOpacity` and `Pressable` elements.
- Bottom safe area inset: use `useSafeAreaInsets().bottom` on top of 48pt tab bar — do not hardcode a fixed value.

**Source:** Carried from `frontend/src/index.css` `--space-*` tokens, converted from px to pt (1:1 on standard density).

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14pt | 400 (Regular) | 1.5 (21pt) |
| Label | 12pt | 600 (SemiBold) | 1.3 (15.6pt) |
| Heading | 20pt | 600 (SemiBold) | 1.2 (24pt) |
| Display | 28pt | 600 (SemiBold) | 1.2 (33.6pt) |

**Usage mapping:**
- Body: chat message text, pipeline lead name secondary line, settings input values
- Label: status badge text, section group headers ("NEW · 3"), button labels
- Heading: screen title (e.g., "Leads"), card lead name primary line, conversation lead name header
- Display: login screen "OttoBot" wordmark only

**Source:** Carried from `frontend/src/index.css` body (14px, 1.5) and h1-level conventions observed in OnboardingWizard.tsx.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0f1117` | Screen backgrounds, FlatList background |
| Secondary (30%) | `#1a1d27` | Cards, list row backgrounds, input fields, modal surfaces |
| Accent (10%) | `#6366f1` | See reserved list below |
| Destructive | `#ef4444` | Escalated badge background, Mark Outcome destructive action only |

**Accent reserved for:**
1. Login button background ("Mag-login")
2. Active tab indicator (bottom navigation bar underline/dot)
3. "Mark as Open" day toggle active state (availability calendar)
4. Focus ring on text inputs (2pt border, not fill)

**Text colors:**
- Primary text: `#f1f5f9`
- Muted text: `#64748b`

**Status badge color pairs (pipeline groups):**

| Status | Background | Text |
|--------|------------|------|
| new | `#334155` | `#94a3b8` |
| in-progress | `#1e3a5f` | `#60a5fa` |
| booked | `#14532d` | `#4ade80` |
| escalated | `#422006` | `#fb923c` |

**Source:** All color values carried verbatim from `frontend/src/index.css` token definitions.

## Navigation

Pattern: Expo Router (file-based routing, SDK 51) with a bottom tab navigator for authenticated screens.

| Tab | Icon | Route |
|-----|------|-------|
| Leads | `list` (MaterialIcons) | `/pipeline` |
| Settings | `settings` (MaterialIcons) | `/settings` |

Login screen: full-screen, no tabs. Redirect to `/pipeline` on successful auth.
Back navigation on Conversation Detail: system back / header back chevron, no custom gesture.

---

## Interaction Contracts

| Interaction | Behavior |
|-------------|----------|
| Lead row tap | Push `/conversation/:leadId` onto stack |
| Pull-to-refresh on Pipeline | Re-fetch leads list from `GET /leads?business_id=` |
| Day toggle (Settings) | Optimistic update → `POST /availability` on Save |
| Login form submit | Disable button + show spinner during Supabase Auth call |
| App foreground from push | Deep-link to `/conversation/:leadId` from notification data |
| Network error | Inline error text (no toast, no modal) — see Copywriting |

## Accessibility

- Minimum touch target: 44pt height on all `TouchableOpacity` / `Pressable`
- `accessibilityLabel` required on icon-only buttons
- `accessibilityRole="button"` on all custom touchables
- `accessibilityState={{ selected: true }}` on active tab
- Color contrast: all text/background pairs from the color table above meet WCAG AA (verified against existing web implementation which uses same hex values)
