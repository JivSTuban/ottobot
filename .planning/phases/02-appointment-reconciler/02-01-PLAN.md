  Required exports:
    - FALLBACK_PHRASE: str = "Tatawagan ka namin para mag-ayos ng oras"
    - DAYS_PH: list[str] = ["Lunes", "Martes", "Miyerkules", "Huwebes", "Biyernes", "Sabado", "Linggo"]
      (weekday() index: 0=Monday matches "Lunes")

  `format_slot_tagalog(dt: datetime) -> str`:
    - hour < 12 → "ika-{hour} ng umaga"
    - hour == 12 → "tanghaling tapat"
    - hour > 12 → "ika-{hour - 12} ng hapon"
    - Returns: f"Mayroon kaming bakante sa {DAYS_PH[dt.weekday()]} ng {dt.strftime('%B %d')} sa {time_str}"

  `compute_next_slots(availability_rows: list[dict], now: datetime | None = None, max_count: int = 2) -> list[datetime]`:
    - availability_rows: each dict has keys day_of_week (int 0-6), start_time (datetime.time or str "HH:MM"), end_time (datetime.time or str "HH:MM")
    - now defaults to datetime.now(tz=timezone(timedelta(hours=8))) — PH local time UTC+8
    - Iterate over next 7 days (today through today+6 inclusive)
    - For each day, check if any availability row matches day_of_week
    - Compute candidate datetime: date + start_time, timezone UTC+8
    - Exclude if candidate_dt <= now + timedelta(hours=2)
    - Collect up to max_count=2 earliest qualifying datetimes; return as list[datetime]
    - Return [] if availability_rows is empty or no qualifying slots

  `async get_available_slots(business_id: str, days_ahead: int = 7) -> list[dict]`:
    - Connect via: db_uri = os.environ.get("SUPABASE_DIRECT_URL") or os.environ.get("SUPABASE_DB_URI", "")
    - Use `async with await psycopg.AsyncConnection.connect(db_uri) as conn:` (RESEARCH.md Pattern 1)
    - Query: SELECT day_of_week, start_time, end_time FROM business_availability WHERE business_id = %s ORDER BY day_of_week, start_time
    - Return list of row dicts; use `[{"day_of_week": r[0], "start_time": r[1], "end_time": r[2]} for r in rows]`
    - Never call asyncio.run() — this is an async function (Pitfall 2)
    - If db_uri is empty string, return [] (graceful degradation for tests without DB)

  Imports needed in slots.py: os, datetime, timezone, timedelta from datetime stdlib; psycopg (already installed per RESEARCH.md)
