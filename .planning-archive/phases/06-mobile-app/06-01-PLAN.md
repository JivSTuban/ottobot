<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile app → FastAPI | JWT Bearer token required; untrusted body params not accepted for business_id |
| FastAPI → Supabase Postgres | Parameterized queries only; no string interpolation |
| FastAPI → Expo Push API | Server-to-server only; mobile never calls Expo API directly |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-01 | Information Disclosure | GET /leads — cross-business data access | mitigate | JWT sub → businesses table join; business_id NEVER from request body |
| T-06-02 | Information Disclosure | GET /leads/{id}/messages — cross-business message access | mitigate | JOIN leads ON business_id in SQL query; ownership checked in DB |
| T-06-03 | Elevation of Privilege | POST /push/send — attacker registers fake token for another business | mitigate | business_id from JWT only; JWT decoded server-side |
| T-06-04 | Tampering | SQLi via lead_id or business_id params | mitigate | parameterized queries via psycopg (existing project pattern) |
| T-06-05 | Spoofing | Invalid expo_token stored | mitigate | ExponentPushToken[...] format check before upsert |
| T-06-SC | Tampering | npm/pip package installs | accept | No new Python packages in this plan; no npm install in this plan |
</threat_model>
