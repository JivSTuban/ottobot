## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Mobile app → Supabase Auth | JWT credential exchange; session persisted via AsyncStorage |
| Mobile app → Expo Push API | Token obtained device-side only; never server-side in mobile code |
| Mobile app → FastAPI /push/send | Token POSTed with auth JWT; server validates and stores |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |

| T-06-06 | Information Disclosure | EXPO_PUBLIC_ env vars in app bundle | accept | Only anon key exposed (by design); service role key never in mobile env |
| T-06-07 | Spoofing | Fake Supabase session via crafted AsyncStorage | accept | Supabase auth handles JWT validation; token expiry enforced server-side |
| T-06-08 | Denial of Service | Push token registration fails silently | mitigate | registerForPushNotificationsAsync wrapped in try/catch in _layout.tsx; app continues without push |
