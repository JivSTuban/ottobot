      class ConnectionManager:
          def __init__(self) -> None:
              self.active_connections: list[WebSocket] = []

          async def connect(self, websocket: WebSocket) -> None:
              await websocket.accept()
              self.active_connections.append(websocket)

          def disconnect(self, websocket: WebSocket) -> None:
              if websocket in self.active_connections:
                  self.active_connections.remove(websocket)

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| WebSocket client (browser) -> FastAPI route | untrusted thread_id; untrusted user text |
| FastAPI -> Supabase Postgres | conversation state crosses network |
| LiteLLM Router -> 3 LLM providers | API keys flow outbound |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-01 | Information Disclosure | thread_id enumeration | mitigate | Reject non-uuid4 thread_ids with close code 1008 (V3 ASVS Session Management); validate_thread_id helper |
| T-05-02 | Tampering | Prompt injection via WS user text | mitigate | User text goes into `{"role":"user", "content":...}` only; never into system prompt; persona prompt is rendered from DEMO_PROFILES (in-code) and validated by Pydantic |
| T-05-03 | Repudiation | Missing NPC 2024-04 AI disclosure on first turn | mitigate | `check_ai_disclosure(rendered)` guardrail in api/guardrails.py; intro template (base.j2) hardcodes phrase |
| T-05-04 | Denial of Service | Cascading 429 from all 3 providers | mitigate | `_429_backoff[thread_id]` 30s holding period; `holding_message_429()` sent to client; LiteLLM Router fallbacks already configured (Plan 03) |
| T-05-05 | Information Disclosure | SUPABASE_DB_URI logged on lifespan error | mitigate | Lifespan try/except wraps Phoenix init only; AsyncPostgresSaver errors propagate via uvicorn but message excludes the URI by default |
| T-05-06 | Tampering | PostgresSaver schema not migrated | mitigate | `await checkpointer.setup()` called inside lifespan (Pitfall 2); test_persistence asserts idempotency |
| T-05-07 | Elevation of Privilege | WebSocket reconnect with stolen thread_id resumes another lead's conversation | accept | Phase 1 demo is single-tenant; thread_id is client-generated uuid4; cross-session auth deferred to Phase 5 (Supabase Auth) |
</threat_model>
